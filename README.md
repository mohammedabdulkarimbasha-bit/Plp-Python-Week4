Week 4 Assignment: Functions in Python

welcome.py: Defines a reusable `welcome()` function to generate personalized greeting strings and prints them for multiple names.
toolbox.py: Contains three utility functions (`double`, `is_pass`, and `greet`) handling mathematical operations, boolean comparisons, and optional default arguments.

The function that was hardest to write was `greet` because it required handling an optional keyword parameter with a default value while correctly formatting string concatenation and punctuation. Working through default arguments helped clarify how Python handles optional parameters seamlessly.
